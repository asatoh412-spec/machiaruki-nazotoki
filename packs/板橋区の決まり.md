# 板橋区の地点を作るときの追加の決まり（AUTHORING.md より優先）

- 区データは「板橋区 文化財一覧（オープンデータ）」。説明文の列が空。入力は場所ごとにまとめてあり、point_name は仮。その場所に何があるか（寺社名など）をまず出典で確かめて地点名にする
- AUTHORING.md の規則1は次に読み替える：sources に必ず
  {"title":"板橋区 文化財一覧（オープンデータ）","publisher":"板橋区","url":"https://www.opendata.metro.tokyo.lg.jp/itabashi/131199_cultural_property.csv","kind":"自治体","accessed":"2026-11-14"} を入れる
- 出典の優先：板橋区の公式サイト（文化財・史跡の解説ページ）、板橋区立郷土資料館、東京都の文化財ページ、寺社の公式、観光協会、Wikipedia
- id は "itabashi-" + records の最初の「行番号」
- 寺の所蔵の仏像・絵画・文書は普段見られない。地点は寺社にし、外から見える物（山門、本堂、墓、碑、樹木など出典で確かめた物）で謎を作る
- 同じ寺社に当たる複数の入力は1地点にまとめる。隣り合う地点が50m以内に重ならないようにする（重なるならまとめるか片方を外す）
- 「〜跡」は説明板・標柱の位置を出典で確かめ、その位置を到着の座標にする。何も見る物がなければ作らない
- 伝統工芸の技術保持者・個人宅・学校や企業の敷地内で外から見られない物は作らない
- 墓は AUTHORING.md の規則8（参拝の可否）
- 座標は国土地理院の住所検索（https://msearch.gsi.go.jp/address-search/AddressSearch?q=東京都...）でも確かめ、明らかに違えば直して notes に書く
- ヒント1とヒント2には、答え（accept の語）やその一部を書かない。ヒント3はほぼ答えでよい
- 由緒も外観も出典で確かめられない物は作らず、報告に「出典なし」と書く
- **画像は今回は探さない。images は空配列 [] にする**（あとでまとめて足す。Wikimedia Commons の制限待ちを避けるため）
- onsite_hints の各項目は text・confidence・source_url を持つ
- sources の accessed は 2026-11-14
