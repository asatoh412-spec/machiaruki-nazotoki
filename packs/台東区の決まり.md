# 台東区の地点を作るときの追加の決まり（AUTHORING.md より優先）

- 区データは「台東区 文化財一覧（オープンデータ）」。説明文の列が空で、ID列が壊れている（Excelの指数表記）ので、入力では行番号を使う。入力は住所ごとにまとめてあり、point_name は仮。その住所に何があるか（寺社名など）を、まず出典で確かめて地点名にする
- AUTHORING.md の規則1は台東区では次に読み替える：sources に必ず
  {"title":"台東区 文化財一覧（オープンデータ）","publisher":"台東区","url":"https://www.city.taito.lg.jp/kusei/online/opendata/iryo/bunkazai.files/20250314_bunkazai.csv","kind":"自治体","accessed":"2026-11-13"} を入れる
- 出典の優先：台東区の公式サイト（www.city.taito.lg.jp の文化財のページ。「台東区の文化財」の解説）、台東区立下町風俗資料館、東京都の文化財ページ、寺社の公式、Wikipedia
- id は "taito-" + records の最初の「行番号」（入力の各レコードの 行番号 の値）
- 寺の所蔵の仏像・文書は普段見られない。地点は寺社にし、外から見える物（山門、本堂、境内の墓・碑・石仏など出典で確かめた物）で謎を作る
- 同じ寺社に当たる複数の入力（隣り合う番地など）は1地点にまとめ、notes に書く
- 座標は国土地理院の住所検索（https://msearch.gsi.go.jp/address-search/AddressSearch?q=東京都台東区...）でも確かめ、合わなければ直して notes に書く
- ヒント1とヒント2には、答え（accept の語）やその一部を書かない。ヒント3はほぼ答えでよい
- 由緒も外観も出典で確かめられない物（住所しか分からない地蔵・庚申塔など）は作らず、報告に「出典なし」と書く
- 画像は images の欄だけに入れる。onsite_hints の各項目は text・confidence・source_url を持つ
- Commons のファイルページを開けないときは Commons の API で作者とライセンスを確かめてよい
- sources の accessed は 2026-11-13
- 台東区のデータの座標は「丁目」単位の代表点で、同じ丁目の別の寺が同じ座標になっている。寺社ごとに必ず位置を確かめて直す（国土地理院の住所検索、寺社の公式の住所、OpenStreetMap の寺社の位置）
- 寺の所蔵品（仏画・仏像・版木・文書）は普段見られない。地点は寺社にし、外から見える物（山門、本堂、墓、碑など出典で確かめた物）で謎を作る
