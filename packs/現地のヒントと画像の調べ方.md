# 追加調査：現地のヒントと解説の画像（街歩き謎解き）

アプリの前提は AUTHORING.md と同じ。到着（地点の50m以内）しても、何を探せばよいか分からないことがある。そこで、到着後に開ける「現地のヒント」と、正解後の解説に出す画像を、地点ごとに調べて足す。

## 1. 現地のヒント（onsite_hints）
地点ごとに、次のことを分かる範囲で書く。1項目1文、短く。
- 探す物：区の説明板（標示板）、石碑、鳥居、山門、建物、墓、樹木など。色や形が分かれば書く
- 現存かどうか：遺構が残っているか、説明板だけか、建物ごと現存か
- すぐ近くの目印：道の角、隣の建物（店名は避け、寺社・公園・学校・坂・交差点などを優先）、門のどちら側か
- 公開の制約：境内に入れるか、道路から見るのか

各項目に「確度」を付ける：
- "出典あり"：ページ（写真付きの記事、区のページ、寺社の公式など）で確かめた
- "未確認"：出典で確かめられないが、一般的な推定（例：新宿区の史跡には区の説明板が立つことが多い）。未確認の項目は書いてもよいが、必ず未確認とする

## 2. 解説の画像（images）
- 使ってよいのは次だけ：
  - Wikimedia Commons の画像（ファイルページで作者とライセンスを確かめる。CC BY / CC BY-SA / CC0 / パブリックドメイン）
  - 著作権の切れた古い絵や写真（国立国会図書館デジタルコレクションなどで「インターネット公開（保護期間満了）」のもの）
- 寺社・個人・観光サイトの写真は使わない
- 地点そのもの、または関係する人物の肖像（パブリックドメインのもの）。1地点に最大2枚
- 見つからなければ空配列でよい。無理に探さない

## 出力
入力の各地点の id ごとに、次の JSON を配列で書き出す。
```json
{
  "id": "shinjuku-...",
  "onsite_hints": [
    { "text": "探す物は区の説明板。門を入って左手に立つ", "confidence": "出典あり", "source_url": "https://..." },
    { "text": "建物は残っておらず、説明板だけがある", "confidence": "未確認", "source_url": null }
  ],
  "images": [
    { "file_page": "https://commons.wikimedia.org/wiki/File:....jpg", "image_url": "https://upload.wikimedia.org/...", "caption": "何が写っているか（短く）", "author": "作者名", "license": "CC BY-SA 4.0", "license_url": "https://creativecommons.org/licenses/by-sa/4.0/" }
  ]
}
```
image_url は upload.wikimedia.org の実ファイルのURL（幅1280pxの縮小版URL「/thumb/.../1280px-...」があればそれ）。ファイルページを実際に開いて作者・ライセンスを確かめたものだけを入れる。
