# 練馬区の地点を作るときの追加の決まり（AUTHORING.md より優先）

- 区データは「練馬区 文化財一覧（オープンデータ、CC BY 4.0）」。説明文の列が空なので、事実は必ず別のページで確かめる
- AUTHORING.md の規則1は練馬区では次に読み替える：sources に必ず
  {"title":"練馬区 文化財一覧（オープンデータ）","publisher":"練馬区","url":"https://www.city.nerima.tokyo.jp/kusei/tokei/opendata/opendatasite/bunka/cultural_property.files/131202_cultural_property.csv","kind":"自治体","accessed":"2026-11-13"} を入れる
- 練馬区の公式サイトには文化財ごとの解説ページ（www.city.nerima.tokyo.jp/kankomoyoshi/annai/rekishiwoshiru/ 以下）がある。まずそこを探す。次に東京都の文化財ページ、寺社の公式、Wikipedia
- id は "nerima-" + records の最初の ID の下4桁（例 nerima-0055）
- 〈非公開〉の付いた物は見られない。〈路上見学のみ〉は道路から見る（access に書く）
- 区データの座標は、別の物でも同じ値になっていることがある。住所で国土地理院の住所検索（https://msearch.gsi.go.jp/address-search/AddressSearch?q=東京都練馬区...）を引き、合わなければ lat/lon を直して notes に書く
- ヒント1とヒント2には、答え（accept の語）やその一部を書かない。ヒント3はほぼ答えでよい
- 由緒も外観も出典で確かめられない物は作らず、報告に「出典なし」と書く
- 画像は images の欄だけに入れる。onsite_hints の各項目は text・confidence・source_url を持つ
- Commons のファイルページを開けないときは Commons の API（https://commons.wikimedia.org/w/api.php?action=query&titles=File:...&prop=imageinfo&iiprop=url|extmetadata&iiurlwidth=1280&format=json）で作者とライセンスを確かめてよい
