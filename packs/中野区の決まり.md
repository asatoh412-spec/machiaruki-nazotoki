# 中野区の地点を作るときの追加の決まり（AUTHORING.md より優先）

- 区データは「中野区 文化財一覧（オープンデータ）」。説明文の列が空で、名称も「地蔵」「庚申塔」だけのものが多い。入力は住所ごとにまとめてあり、point_name は仮。その住所に何があるか（寺社名など）を、まず出典で確かめて地点名にする
- AUTHORING.md の規則1は中野区では次に読み替える：sources に必ず
  {"title":"中野区 文化財一覧（オープンデータ）","publisher":"中野区","url":"https://www2.wagmap.jp/nakanodatamap/nakanodatamap/opendatafile/map_33/CSV/opendata_550120.csv","kind":"自治体","accessed":"2026-11-13"} を入れる
- 出典の優先：中野区の公式サイト（www.city.tokyo-nakano.lg.jp の文化財・史跡のページ、「なかのの文化財」）、中野区立歴史民俗資料館、東京都の文化財ページ、寺社の公式、Wikipedia
- id は "nakano-" + records の最初の NO を数として書いたもの（例 NO 0000000061 → nakano-61、1000000001 → nakano-1000000001）
- 寺の所蔵の仏像・文書は普段見られない。地点は寺社にし、外から見える物（山門、本堂、境内の墓・碑・石仏など出典で確かめた物）で謎を作る
- 同じ寺社に当たる複数の入力（隣り合う番地など）は1地点にまとめ、notes に書く
- 座標は国土地理院の住所検索（https://msearch.gsi.go.jp/address-search/AddressSearch?q=東京都中野区...）でも確かめ、合わなければ直して notes に書く
- ヒント1とヒント2には、答え（accept の語）やその一部を書かない。ヒント3はほぼ答えでよい
- 由緒も外観も出典で確かめられない物（住所しか分からない地蔵・庚申塔など）は作らず、報告に「出典なし」と書く
- 画像は images の欄だけに入れる。onsite_hints の各項目は text・confidence・source_url を持つ
- Commons のファイルページを開けないときは Commons の API で作者とライセンスを確かめてよい
- sources の accessed は 2026-11-13
