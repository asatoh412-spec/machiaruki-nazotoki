# 品川区の地点を作るときの追加の決まり（AUTHORING.md より優先）

- 区データは「品川区 指定文化財（オープンデータ、地区別・都指定・国指定のCSV）」。各レコードに「コメント」（短い解説）と緯度・経度がある。入力は所在地ごとにまとめてあり、point_name は仮。その所在地に何があるか（寺社名など）を確かめて地点名にする
- AUTHORING.md の規則1は品川区では次に読み替える：sources に必ず
  {"title":"品川区 指定文化財（オープンデータ）","publisher":"品川区","url":"https://www.opendata.metro.tokyo.lg.jp/shinagawa/bunkazai_shinagawa.csv","kind":"自治体","accessed":"2026-11-14"} を入れる（大崎・大井・荏原地区の物は、それぞれ bunkazai_oosaki.csv / bunkazai_ooi.csv / bunkazai_ebara.csv の URL にする。都・国指定は bunkazai_tokyoto.csv / bunkazai_kuni.csv）
- 区データの「コメント」は一次出典として使ってよい。それ以外の事実は実際に開いたページで確かめる。出典の優先：品川区の公式サイト（www.city.shinagawa.tokyo.jp の文化財のページ）、品川区立品川歴史館、東京都の文化財ページ、寺社の公式、Wikipedia
- id は "shinagawa-" + records の最初の「行番号」
- 寺の所蔵の仏像・絵画・文書は普段見られない。地点は寺社にし、外から見える物（山門、本堂、墓、碑、樹木など出典で確かめた物）で謎を作る
- 同じ寺社に当たる複数の所在地（隣り合う番地）は1地点にまとめ、notes に書く。隣り合う地点が50m以内に重ならないようにする
- 祭礼・囃子・神楽の行事のレコードは、その神社の seasonal（時期が出典で分かれば）と解説で扱う
- 個人宅・企業の敷地・学校の敷地内で外から見られない物は作らない
- 墓は AUTHORING.md の規則8（参拝の可否）
- ヒント1とヒント2には、答え（accept の語）やその一部を書かない。ヒント3はほぼ答えでよい
- 由緒も外観も出典で確かめられない物は作らず、報告に「出典なし」と書く
- 画像は images の欄だけに入れる。onsite_hints の各項目は text・confidence・source_url を持つ
- Commons の API は連続で呼ぶと制限される（429）。間を空け、ファイルページを開けないときは API で作者とライセンスを確かめてよい
- sources の accessed は 2026-11-14
