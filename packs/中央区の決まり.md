# 中央区の地点を作るときの追加の決まり（AUTHORING.md より優先）

- 区データは「中央区 文化財一覧（オープンデータ）」。説明文の列が空で、ID列が壊れている（Excelの指数表記）ので、入力では行番号を使う。入力は住所ごとにまとめてあり、point_name は仮。その住所に何があるか（寺社名など）を、まず出典で確かめて地点名にする
- AUTHORING.md の規則1は中央区では次に読み替える：sources に必ず
  {"title":"中央区 文化財一覧（オープンデータ）","publisher":"中央区","url":"https://www.city.chuo.lg.jp/documents/984/bunkazai.csv","kind":"自治体","accessed":"2026-11-13"} を入れる
- 出典の優先：中央区の公式サイト（www.city.chuo.lg.jp の文化財のページ。「中央区文化財」の解説）、中央区立郷土天文館（タイムドーム明石）、東京都の文化財ページ、寺社の公式、Wikipedia
- id は "chuo-" + records の最初の「行番号」（入力の各レコードの 行番号 の値）
- 寺の所蔵の仏像・文書は普段見られない。地点は寺社にし、外から見える物（山門、本堂、境内の墓・碑・石仏など出典で確かめた物）で謎を作る
- 同じ寺社に当たる複数の入力（隣り合う番地など）は1地点にまとめ、notes に書く
- 座標は国土地理院の住所検索（https://msearch.gsi.go.jp/address-search/AddressSearch?q=東京都中央区...）でも確かめ、合わなければ直して notes に書く
- ヒント1とヒント2には、答え（accept の語）やその一部を書かない。ヒント3はほぼ答えでよい
- 由緒も外観も出典で確かめられない物（住所しか分からない地蔵・庚申塔など）は作らず、報告に「出典なし」と書く
- 画像は images の欄だけに入れる。onsite_hints の各項目は text・confidence・source_url を持つ
- Commons のファイルページを開けないときは Commons の API で作者とライセンスを確かめてよい
- sources の accessed は 2026-11-13
- 中央区のデータの座標は、おおむね番地単位で正確。ただし住所が「〜先」「〜他」の物（橋の親柱、跡の碑）は、碑や親柱が見られる位置を出典で確かめる
- 老舗の店（文書・道具の所蔵者）は、AUTHORING.md の「店の扱い」に従ってよい（話のある店として地点にできる）。営業時間・定休日を出典で確かめて access に書く。所蔵品は普段見られない前提
