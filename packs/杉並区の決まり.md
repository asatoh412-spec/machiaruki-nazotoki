# 杉並区の地点を作るときの追加の決まり（AUTHORING.md より優先）

- 区データは「杉並区 文化財一覧（オープンデータ）」。説明文の列が空で、ID列が壊れている（Excelの指数表記）ので、入力では行番号を使う。入力は住所ごとにまとめてあり、point_name は仮。その住所に何があるか（寺社名など）を、まず出典で確かめて地点名にする
- AUTHORING.md の規則1は杉並区では次に読み替える：sources に必ず
  {"title":"杉並区 文化財一覧（オープンデータ）","publisher":"杉並区","url":"https://www.city.suginami.tokyo.jp/documents/7581/r8-bunkazai-csv.csv","kind":"自治体","accessed":"2026-11-13"} を入れる
- 出典の優先：杉並区の公式サイト（www.city.suginami.tokyo.jp の文化財のページ。指定・登録文化財ごとの解説PDFがある）、杉並区立郷土博物館、東京都の文化財ページ、寺社の公式、Wikipedia
- id は "suginami-" + records の最初の「行番号」（入力の各レコードの 行番号 の値）
- 寺の所蔵の仏像・文書は普段見られない。地点は寺社にし、外から見える物（山門、本堂、境内の墓・碑・石仏など出典で確かめた物）で謎を作る
- 同じ寺社に当たる複数の入力（隣り合う番地など）は1地点にまとめ、notes に書く
- 座標は国土地理院の住所検索（https://msearch.gsi.go.jp/address-search/AddressSearch?q=東京都杉並区...）でも確かめ、合わなければ直して notes に書く
- ヒント1とヒント2には、答え（accept の語）やその一部を書かない。ヒント3はほぼ答えでよい
- 由緒も外観も出典で確かめられない物（住所しか分からない地蔵・庚申塔など）は作らず、報告に「出典なし」と書く
- 画像は images の欄だけに入れる。onsite_hints の各項目は text・confidence・source_url を持つ
- Commons のファイルページを開けないときは Commons の API で作者とライセンスを確かめてよい
- sources の accessed は 2026-11-13
